1 Trip Generation

Estimates the total number of trips produced by and attracted to each zone based on land use and socioeconomic data.

Zone Population Jobs Trip Production Trip Attraction
Formula:

Productions = Population × Trip Rate
Attractions = Jobs × Attraction Factor

2 Trip Distribution (Gravity Model)

Distributes trips between zones using a gravity model based on trip ends and travel impedance (distance/time).

From \ To Zone A Zone B Zone C Total
Gravity Model:

Tij = Pi × (Aj × f(dij)) / Σ(Ak × f(dik))
Where f(d) = 1/d² (distance decay function)

3 Mode Choice (Modal Split)

Determines which transport mode people use based on utility (cost, time, comfort) for each mode.

Logit Model:

P(mode) = exp(Umode) / Σ exp(Uk)
U = β₀ + β₁×cost + β₂×time + β₃×comfort

4 Route Assignment

Assigns trips to specific routes in the network, typically using shortest path or equilibrium assignment.
